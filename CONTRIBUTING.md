# 参与反馈 / Contributing

本仓库接受产品问题、键盘适配申请和文档修改。应用源代码未在这里公开，因此这里没有应用构建或本地开发流程。

This repository accepts product issues, keyboard support requests and documentation improvements. Application source code is not published here, so there is no application build or local development workflow in this repository.

## 问题 / Issues

提交前先搜索已有问题。报告中请包含完整型号、系统与浏览器版本、连接方式、复现步骤和实际结果。请区分真机结果与模拟测试结果。

Search existing issues first. Include the full model, OS/browser versions, connection mode, reproduction steps and actual results. Distinguish physical-device results from simulated tests.

## 文档 / Documentation

欢迎通过 Pull Request 修正错别字、翻译和使用说明。修改通用说明时，请同步检查中文和英文版本；不确定的翻译可以在 PR 中注明。

Pull requests for corrections, translations and usage notes are welcome. Check both language versions when changing shared instructions, and flag any translation questions in the PR.

## 适配 / Keyboard support

附上准确型号、官方产品页面、官方配置工具链接，以及可见的固件版本或设备信息。请不要上传凭据或不相关的个人文件。

Provide the exact model, official product/configuration-tool links and available firmware or device details. Do not upload credentials or unrelated personal files.
