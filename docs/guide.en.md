# User guide

[Back to overview](../README.en.md) · [简体中文](guide.zh-CN.md)

## Before connecting

Find the exact model in the [directory](https://letmedrive.cn/keyboards). Suffixes such as Pro, HE or Wireless may identify different hardware.

Use desktop Chrome or Edge and start with a USB data cable. Back up important existing settings with an available configuration tool first.

## Connect and configure

1. Open [Let Me Drive](https://letmedrive.cn) and choose the connect action.
2. Select the keyboard in the browser permission dialog. Disconnect other keyboards if several entries are difficult to distinguish.
3. Check the detected model before opening remapping, macros, lighting or Hall-effect controls.
4. Start with one easy-to-check setting, such as a key assignment or lighting effect.
5. Follow the app's save/write instructions and test the result on the device.

## Saving and backups

Live preview, writing and onboard persistence can differ by model. Check both the app's result and the physical keyboard. Reconnect to verify settings that should persist between sessions.

Include the model and date in exported filenames. Check the model and format before importing; do not assume profiles are interchangeable between different keyboards.

## Connection troubleshooting

1. Confirm you are using desktop Chrome or Edge.
2. Check that the USB cable supports data; try another cable or connect directly to the computer.
3. Switch to wired mode, or check whether the model supports receiver configuration.
4. Close vendor tools and other browser tabs connected to the same device, then retry.
5. Disconnect the site's device session in the browser and grant access again.
6. Check that the exact model is listed, including any experimental status.

If connection still fails, record the device name shown in the chooser, OS and browser versions, then [report an issue](https://github.com/MukiCheung/letmedrive/issues/new?template=bug-en.yml).

## Useful report details

- Brand, full model and firmware version, if available.
- OS, browser version and connection mode.
- Steps from connection to failure.
- Expected and actual behavior, and whether the issue is reproducible.
- Error messages or device information screenshots. Remove unrelated personal information before posting publicly.

For an unlisted model, use the [support request form](https://github.com/MukiCheung/letmedrive/issues/new?template=support-request-en.yml) and include official product and configuration-tool links.
