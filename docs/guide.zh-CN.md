# 使用指南

[返回首页](../README.md) · [English](guide.en.md)

## 连接前

在[型号目录](https://letmedrive.cn/keyboards)查找完整型号。键盘的 Pro、HE、无线版等后缀可能对应不同硬件，不能只看系列名称。

使用电脑上的 Chrome 或 Edge，优先以 USB 数据线连接。已有重要配置时，先通过可用的配置工具备份。

## 连接与修改

1. 打开 [Let Me Drive](https://letmedrive.cn)，点击连接键盘。
2. 在浏览器授权窗口选择对应键盘。若有多个相似设备，先断开其他键盘再确认。
3. 核对页面识别出的型号，再进入改键、宏、灯光或磁轴页面。
4. 先修改一个容易验证的选项，例如一个按键或灯效。
5. 按页面提示完成保存或写入，检查键盘实际响应。

## 保存与备份

不同型号的即时预览、写入和板载保存行为可能不同。确认配置时，既要看页面提示，也要在设备上测试；需要保留到下次使用的配置，可断开重连核对。

导出文件建议在文件名中注明型号和日期。导入前核对型号与格式，不要直接把一款键盘的配置导入另一款。

## 连接排查

按顺序检查：

1. 浏览器是否为桌面 Chrome 或 Edge。
2. USB 线能否传输数据；必要时换线或直接连接电脑 USB 口。
3. 键盘是否切到有线模式，接收器模式是否被该型号支持。
4. 是否有官方驱动或另一个网页正在连接同一设备；关闭后重试。
5. 在浏览器中断开该站点的设备连接，再重新授权。
6. 查看目录中是否列出了准确型号，以及是否标为实验性。

仍无法连接时，记录设备选择窗口里显示的名称、系统和浏览器版本，再[提交问题](https://github.com/MukiCheung/letmedrive/issues/new?template=bug.yml)。

## 反馈应包含什么

- 品牌、完整型号、固件版本（如可见）。
- 系统、浏览器版本、连接方式。
- 从连接到问题发生的具体步骤。
- 预期结果和实际结果；是否能稳定复现。
- 页面报错或设备信息截图。公开提交前遮住无关个人信息。

型号未收录请使用[适配申请](https://github.com/MukiCheung/letmedrive/issues/new?template=support-request.yml)，附上官方产品页和配置工具链接。
